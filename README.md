# StockFlow

A role-based Inventory and billing management system built in C++ using OOP, using binary file I/O, and a console UI.

## Features

- Role-based login (Controller / Admin / Employee)
- Inventory management (Add, Edit, Delete, View)
- Billing system with receipt generation.
- Credential management system.
- Binary file storage for persistent data.
- Low stock alerts.

## Tech Stack

- Language  : C++
- Paradigm  : Object Oriented Programming
- Storage   : Binary File I/O (.dat) + Text receipts (.txt)
- Platform  : Windows (Console Application)

## How to Run

1. Clone the repository.
2. Open in your IDE (Dev C++ / Code::Blocks / VS). Suggested : (Embarcadero Dev-C++)
3. Compile and Run.
4. Default Controller credentials are Given at the End.
